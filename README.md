# 🔥 Deck do Nilo — Steakhouse & Parrilla

Site institucional (landing page) do **Deck do Nilo**, steakhouse de cortes nobres na
parrilla em **Jaraguá do Sul — SC**.

> _"O som que o seu jantar faz."_ — Cortes nobres na brasa, ambiente rústico e acolhedor.
> Sempre a melhor opção pra você.

## ✨ Sobre o site

Página única, responsiva e sem dependências de build. Feita com HTML, CSS e JavaScript
puro — leve, rápida e pronta pra publicar.

Destaques da experiência:

- **Hero cinematográfico** com brasa animada (partículas em `<canvas>`) e brilho pulsante.
- **Paleta quente** de brasa, ouro e carvão, com textura de grão de filme.
- **Animações de scroll** suaves via `IntersectionObserver`.
- **Seções**: Sobre · Cortes (cardápio) · Experiência · Horários & Localização · Reserva.
- **Integração WhatsApp** para reservas (`wa.me`) e botão flutuante.
- **Mapa** com localização real integrado.
- **Acessível**: respeita `prefers-reduced-motion`, navegação por teclado e labels ARIA.

## 🚀 Como publicar

É um site estático — basta servir os arquivos.

- **GitHub Pages**: ative o Pages apontando para a branch com estes arquivos.
- **Local**: abra o `index.html` no navegador, ou rode `python3 -m http.server`.
